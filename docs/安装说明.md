# MCSManager 存档备份插件

版本 1.1（2026-09-22）· Windows / Linux 通用

> 第一个公开版本。仓库里的 `src/mc-backup.js` + `web/card-backup.html` + 本说明就是全部，
> 安装只要 Node（MCSManager 自带），Windows / Linux 同一份代码。

## 这是什么

给 MCSManager（面板 + 节点）用的 Minecraft 存档备份组件，装完**面板首页会出现一张「存档备份」卡片**。

- **自动存档**：默认每 10 分钟给每个服务端存一份，**增量（硬链接）只记录变化量**，磁盘占用很小
- **自动存档对齐系统整刻**：10 分钟间隔就是 12:00 / 12:10 / 12:20…，2 小时间隔就是 12:00 / 14:00…（不会因为程序什么时候启动而一直偏着几分钟）；
  卡片上会显示「下次自动保存 12:50:00」，右上角还有本机系统时间可以对照
- **手动保存（立刻保存 / 全部保存）自成一条链**：标成「手动档」，**不进自动保存循环**（不会推迟下一次自动存档），
  也**不会被自动的时间段轮转清掉**。
  - **立刻保存（增量）**：把变化**写进最近那份手动档**（没变的不动、源里删掉的也跟着删），**不会多出一份**；
    里面没有手动档时先建一份（接着最新那份做增量，不会白抄一次完整复制）
  - **全部保存（完整）**：另起一份独立的完整复制，可以单独拿走；之后点「立刻保存」就是刷新这一份
  - 手动档默认最多留 20 份（配置里 `manualKeep` 可改），卡片存档下拉里单独一组「手动保存」，
    被刷新过的会标注「刷新于 时:分」
- **分档保留：一档两列「增量留几份 / 完整留几份」，填 0 就是不存**（面板设置里直接改）。默认
  「10 分钟档 增量 6 / 完整 0 · 2 小时档 增量 1 / 完整 0」（就是当前线上在用的那套）。
  **时间直接选分钟 / 小时 / 天**（下拉里有 5 分钟、30 分钟、1 小时、2 小时、12 小时、1 天、7 天…），不用自己拿分钟换算。
  - **增量**：最小那档按「最新 K 份」滚动；粗档按**自然时间段**各钉一份（1 小时档 = 每个整点那一小时留最早的一份，
    2 小时档 = 每 2 小时一段留最早的一份），时间段一过锚点就固定，**10 分钟档转多少圈都挤不掉它**
  - **完整档**（点「全部保存」存出来的独立一份）：按同一张档位表留，粗档锚点一定取自**更早、还没被占用**的时间段，
    所以拿到的是几份不同时间的完整档；某一档的完整份数填 0，就是这一档不要完整档
  - 存档下拉里按档位分组显示：「完整存档（最近 N 份）」「完整 · 1 小时档」「完整 · 2 小时档」「增量 · 10 分钟档 / 1 小时档 / 2 小时档」
- **有进度条**：正在存档 / 导出 / 回档时，卡片上会显示「已处理 1240/2090（59%）· 已用 3.2 秒」这样的进度条；做完之后进度条变绿、满格并显示「✔ 存档完成：文件名（新写入 N 个 / 用时 X 秒）」，保留 90 秒再收起
- **面板卡片上能做的事**：
  - 卡片默认只留主路径：**选服务端 → 选目标（整个存档 / 某个世界 / 某个玩家）→ 选存档 → 点「还原」**，加保存和导出，一屏能看完
  - **「高级功能」按钮**（默认收起）：坐标级的**只还原某个区块 / 还原整个区域 / 查区块历史**、删除存档（两次确认）、玩家数据转移都在里面，平时不占地方
  - 立刻保存（可选「增量保存」或「全部保存」），做完会告诉你结果（完整还是增量、新写入多少文件）
  - 选目标还原：整个存档 / 某个世界（含 GTNH 那种个人维度）/ 某个玩家 —— 目标和存档各一个下拉
  - 导出：整个服务端（含 mods）/ 纯净服务端（不含存档和玩家）/ 整份存档 / 单个世界 / 单个玩家，且能选「带全部玩家数据 / 不带 / 只带某一个」
    - 「整个服务端」含存档 → **会先自动停服**（避免把人正在写的世界拷成半截），导完自动开服；「纯净服务端」不含存档 / 日志 / 玩家身份文件（ops、usercache、journeymap 等），**不用停服**，导出说明里会列出排除项和开服后要自己设的命令
  - 给世界写备注（GTNH 的个人维度 `DIM-xxx` 建议都标上是谁的岛）
- **全局设置 + 单个服务端单独设置**：存档间隔、分档保留、备份内容都能按服务端单独覆盖
- 下拉选择**不会被自动刷新弹回默认**（选中的目标、存档、导出方式都会记住）

## 需要什么

**只要机器上有 `node`** —— MCSManager 本身就是 Node 应用，装了面板的机器一定有（Windows 版自带、Linux 版靠系统 node 跑）。
不需要额外安装 PowerShell / Java / Python 之类的东西。

## Windows 安装

1. 把这三个文件放到同一个文件夹，例如 `D:\MCSM-backup-plugin\`（说明文件可放别处）：
   - `mc-backup.js`
   - `card-backup.html`
   - `安装说明.md`
2. 在该文件夹打开 PowerShell（或 CMD），执行：

   ```
   node mc-backup.js install --service
   ```

   它会依次问：面板地址（默认 `http://127.0.0.1:23333`）、面板账号、面板密码、节点 ID（面板「节点」页面能看到）、
   存档备份目录（**必须和游戏服在同一个盘**，例如游戏服在 E 盘就用 `D:\MC\_backups`，硬链接才能省空间）。

   不想一条条回答就用默认值：

   ```
   node mc-backup.js install --service --yes
   ```

   （之后也可以改 `mc-backup-config.json`）
3. 刷新面板：首页出现「存档备份」卡片，实例列表出现「备份服务」→ **点一下启动**，
   并在实例设置里打开「随节点自动启动」（以后重启节点会自己拉起）。
4. 完事。备份按点自己跑，卡片上能看到进度条和「上次快照 X 秒 / N 个文件（新写入 M 个）」。

## Linux 安装

1. 装好 MCSManager 面板和节点，并在网页里创建管理员账号。
2. 把文件拷到机器上，例如 `/opt/mcsm-backup/`。
3. 进该目录执行：

   ```
   node mc-backup.js install --service
   ```

   （或 `--service --yes` 用默认值；备份目录建议用 `/srv/backups` 这种和游戏服同一挂载点的目录）
4. 刷新面板：首页出现卡片，实例列表里点启动「备份服务」。

> 一键安装会自动完成：写配置 → 把插件装到 MCSM 目录旁边（`D:\MCSM\backup-plugin` / `/opt/mcsmanager/backup-plugin`，
> 因为节点账户要能读能写）→ 把卡片放进面板并注册到首页布局 → 在面板里创建「备份服务」实例。
> 如果提示「面板登录失败」，说明账号密码不对或面板还没创建管理员，卡片也可以手动加：
> 面板右上角「自定义布局 → 添加 → 扩展页面卡片」，地址填 `/upload_files/card-backup.html`。

## 常用命令

```
node mc-backup.js status      # 刷新卡片读的状态文件
node mc-backup.js snapshot    # 立刻给所有开启备份的服务端各存一份
node mc-backup.js snapshot -i 实例名
node mc-backup.js list        # 列出所有快照
node mc-backup.js watch       # 常驻模式（面板里的「备份服务」跑的就是它）
```

## 配置文件在哪

一键安装会把插件复制到 MCSM 目录旁边（`D:\MCSM\backup-plugin\` 或 `/opt/mcsmanager/backup-plugin/`），
**「备份服务」实例用的就是那一份 `mc-backup-config.json`**。平时不用手改，面板卡片上的「设置」更直观：
存档间隔、分档保留、备份内容、存档位置、导出位置，都能在面板里改，并且支持「全局 / 单个服务端」两套。

## 常见问题

- **卡片显示「读取失败」或一直读取中**：状态文件还没生成，到插件目录跑一次 `node mc-backup.js status`
- **备份目录选哪**：必须和游戏服**同一个盘/挂载点**。跨盘硬链接用不了，每份快照都要完整复制，很费空间
- **份数为什么不变**：分档保留会在存新快照的同时清掉不符合档位的旧快照，所以总数通常稳定（卡片会显示「完整 X / 增量 Y」）
- **想临时关掉自动存档**：面板实例列表把「备份服务」停掉；只想关某一个服务端，卡片上选它点「停止备份」
- **点了保存没看到进度条**：队列最多 60 秒才轮到执行，卡片会自动盯 150 秒；增量快（通常 1 秒内），可能只看到绿色的「✔ 存档完成」。想看清过程就点「全部保存」或导出整份存档
- **换了新卡片但面板上没变化**：面板对 `/upload_files/` 下的卡片文件发的是 `Cache-Control: max-age=86400`，也就是浏览器会缓存 **24 小时**，而它靠 URL 上的 `?v=` 版本号判断要不要重新下载。更新卡片文件后，去面板里把这张卡片重存一次（或把 `面板目录\web\data\layout.json` 里 `card-backup.html?v=` 后面那串数字改掉），再刷新页面即可
- **回档会不会弄坏服务器**：回档/玩家转移前会**先自动停服、把当前文件另存一份**（`_manual` 目录），做完自动开服；只想看效果不动线上，命令行加 `-RestoreTo <目录>`
- **完全卸载**：面板实例列表删掉「备份服务」→ 删掉面板里的卡片 → 删掉插件目录。备份文件在你指定的备份目录里，自己决定留不留

## 兼容性

- 备份文件格式与旧版 PowerShell 版完全一致，**能无缝接管已经存在的快照**
- Windows 10/11、Windows Server、主流 Linux 发行版（已验证 Ubuntu）都能跑
- GTNH（1.7.10）已适配：`World` 大写目录、`players\名字.dat`、个人维度 `DIM-xxx`、`serverutilities`、`journeymap`、`java9args.txt`、`startserver-java9.bat` 都会正确处理
