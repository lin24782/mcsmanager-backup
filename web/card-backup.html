备份内容 = 这个实例里要备份哪些目录/文件（用逗号分隔，相对实例目录）。 GTNH 这类整合默认已带上 serverutilities / journeymap / TCNodeTracker / visualprospecting / local / customnpcs，目录不存在会自动跳过。
每档两列：增量留几份 + 完整留几份，填 0 就是不存 （默认给的就是线上在用的那套：10 分钟档 增量 6 / 完整 0 · 2 小时档 增量 1 / 完整 0）。
时间直接选分钟 / 小时 / 天，不用自己换算成分钟。
增量：最小那档按「最新 K 份」滚动；更粗的档按自然时间段各钉一份（1 小时档 = 每个整点那一小时留最早的一份， 2 小时档 = 每 2 小时一段留最早的一份），时间段一过锚点就固定，10 分钟档转多少圈都挤不掉它。
完整档（点「全部保存」存出来的独立一份）：也按档位留，粗档锚点一定取自更早、还没被占用的时间段， 所以会拿到几份不同时间的完整档；某一档填 0 就是这一档不存完整档。
间隔要大于等于上面的存档间隔，改了会立刻按新策略清一次旧快照。
